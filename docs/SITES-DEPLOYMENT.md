# ChatGPT Sites deployment

This repository is the editable source copy for the existing ChatGPT Site associated with `.openai/hosting.json`.

The live Site is updated from ChatGPT Sites, not GitHub Pages. Open the existing Site in ChatGPT, edit it there, review the preview, and publish the new version.

The `.openai/hosting.json` file must remain in the source package so the existing Site identity can be continued.
