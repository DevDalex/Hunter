# Succession Visual Redesign — Batch 3

## Objective

Batch 3 turns the people, royal-family, faction, and institution surfaces into a premium chapter-bounded intelligence archive without changing canonical records, routing, research conclusions, source provenance, or spoiler behavior.

The visual ambition is deliberately high: cinematic identity stages, operational command surfaces, status-aware records, information-rich chronology, responsive hierarchy views, and accessible alternatives for every advanced visualization.

## Hours 25–29 — Character intelligence command

### Hour 25 — Character directory

The character directory becomes a personnel intelligence command center with:

- an operational overview hero;
- explicit-state coverage visualization with a textual equivalent;
- active, deceased, exceptional, total, visible, and operational-layer metrics;
- sticky multi-dimensional filtering;
- active-filter chips and one-step reset;
- responsive grid and compact-index modes.

### Hour 26 — Character cards

Character cards become status-aware intelligence records with:

- cinematic portrait framing and maintained fallback behavior;
- explicit life-state treatment;
- operational-layer classification;
- current operational summary;
- body, threat, protection, and role facts;
- separate active, deceased, exceptional, and unresolved visual states;
- pointer enhancement without hiding content on touch devices.

Status meaning remains available through text and structure rather than color alone.

### Hour 27 — Character profile headers

The character profile header becomes a full identity stage with:

- dominant portrait treatment;
- record identifier and entity classification;
- role, operational layer, life state, aliases, and selected chapter;
- chapter checkpoint navigation and latest-authorized control;
- retained directory return path;
- responsive single-column mobile composition.

### Hour 28 — Character dossier sections

The character dossier is reorganized into an intelligence hierarchy:

- current operational state;
- role mandate and authority;
- assignments and reporting roles;
- relationships and institutional affiliations;
- Nen intelligence;
- active events;
- protection and threat assignments;
- evidence and source records.

A sticky local dossier navigator provides direct access to Overview, State, Operations, Chronology, and Evidence.

### Hour 29 — Chronology and status changes

The lifetime chronology becomes a multi-kind intelligence lane for:

- state;
- movement;
- assignment;
- relationship;
- event;
- appearance.

Records active at the selected chapter receive an explicit textual and structural marker. The separate state-history ledger retains certainty, body state, consciousness state, and unresolved questions.

## Advanced presentation boundaries

- New CSS uses semantic archive tokens and introduces no raw hexadecimal colors.
- No new visual layer depends on `!important`.
- Motion is restrained and disabled through `prefers-reduced-motion`.
- Touch layouts do not depend on hover.
- Mobile controls retain 44px targets.
- Existing canonical selectors and chapter-bounded dossier APIs remain authoritative.
