## Locked architecture-page contract

The architecture portal fills the complete browser viewport with no horizontal or vertical page scrollbar. It retains the approved monochrome architecture composition, the seven top-level destinations, the four numbered workspace modules, Library Tools, Preserved Contracts, the specification legend, and the miniature page-shell map.

The portal now includes:

- aligned upper workspace rows and lower specification band
- balanced widescreen, standard-desktop, and narrow-laptop spacing
- unbroken labels and readable technical copy
- whole-surface links, hover, focus, pressed, and current states
- contextual route feedback for every major destination
- approved document metadata and versioning
- interactive miniature shell shortcuts
- keyboard, forced-colors, reduced-motion, resize, zoom, and viewport locks
- browser-captured 1440×1000 and 1920×1080 visual baselines
- explicit regression assertions for edge-to-edge geometry and aligned modules

## Deferred by decision

Tablet/mobile architecture-page recomposition is intentionally **not part of this lock pass**. This change does not introduce a new stacked, layered, or mobile-specific architecture composition. The existing viewport behavior remains untouched below the desktop/laptop composition boundary.

## Change policy

After this lock, Phase 3 work changes the destination workspaces rather than the architecture portal. Changes to this page require an explicit architecture-contract revision, a version update, and renewed browser baselines.
